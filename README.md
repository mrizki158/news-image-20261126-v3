## How it works

`main.py` (Python 3.13 standard library only) copies `entry.png` to the output
directory (`MAKEFUN_OUTPUT_DIR`, default `/output`). `build_image.py` is the
program that drew `entry.png` (1024×1024 PNG, Pillow); it is not needed at run
time. Running `main.py` twice writes byte-identical output.
